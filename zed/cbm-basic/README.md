# CBM BASIC (Zed language)

One language for VIC-20, C64, and MEGA65 listings:

- **Name:** CBM BASIC  
- **Files:** `.bas`, `.m65`  
- **Snippets:** `wht` → `{wht}`, `clr` → `{clr}`, `red`, `orng`, `graphic`, …

Install **once**: Zed → **Install Dev Extension** → this folder (`~/CBM/zed/cbm-basic`).

Machine colour themes stay in `zed/vic20-basic`, `zed/c64-basic`, and mega65-zed. Do not register a second language named CBM BASIC in those extensions.
