# Commodore 64 programs

Each program is a folder:

```
C64/<name>/
  README.md
  src/          ; .bas (BASIC 2.0) or .asm (64tass)
  export/       ; .prg and .d64
```

NTSC. BASIC load address `$0801` (2049).

## Zed

Open **this folder** as the workspace:

```bash
~/CBM/scripts/retro c64
```

Listing on the left (C64 blue), Grok in the **bottom** terminal (black/green). Install and tasks: [`../zed/c64-basic/README.md`](../zed/c64-basic/README.md).
